# AutoCAD 小遊戲

蘋果爸的兩個 AutoCAD 指令小遊戲，也放在「論壇資源島」的 🎮 遊戲島。

| 遊戲 | 網址 | 檔案 |
|---|---|---|
| ⌨️ AutoCAD 指令快打（60 秒點出正確指令） | https://kv1012tiger.github.io/autocad-game/ | `index.html` |
| 🏃 AutoCAD 指令跑酷（看中文提示跑向正確指令） | https://kv1012tiger.github.io/autocad-game/runner/ | `runner/index.html` |

- 這個 GitHub 專案是兩個遊戲的正本；Dropbox 裡的「遊戲獨立網頁(GitHub)」「遊戲小工具(嵌入版)-2」是舊備份。
- 兩個遊戲各有自己的排行榜（Google 試算表 + Apps Script），網址寫在各自的 HTML 裡。
- `autocad_game_play.html` 是指令快打的舊檔名，內容和 `index.html` 相同，保留給舊連結。
- `thumb.jpg`、`runner/thumb.jpg` 是遊戲島卡片用的縮圖；`og-image.*` 是分享到 LINE、Facebook 的縮圖。
